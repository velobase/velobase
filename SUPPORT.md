# Support

Use [GitHub Discussions](https://github.com/velobase/velobase/discussions) for integration questions, design ideas, and examples. Use [GitHub Issues](https://github.com/velobase/velobase/issues) for reproducible bugs and scoped feature requests.

Before asking for help, check the README, API guide, state machine, and existing issues. Include the Velobase version or commit, Node.js and PostgreSQL versions, expected behavior, actual behavior, and a minimal reproduction with secrets removed.

For vulnerabilities, do not open a discussion or issue. Follow [SECURITY.md](SECURITY.md) and use GitHub private vulnerability reporting.

Community support is best effort. The repository does not imply an uptime, response-time, or compatibility SLA.
